# Répertoire des Données (Data)

Ce dossier est dédié aux données opérationnelles, fichiers de test et relevés expérimentaux du projet :

* `gcode/` : Motifs de broderie vectorisés et fichiers G-code générés pour les tests machine.
* `mesures/` : Relevés au multimètre/oscilloscope, chronogrammes, logs série de communication.
